### Что это  

В этом репозитории хранится исходный код языка Neniy.  
**Замечание**: проект все еще находится в разработке, но при этом уже работает для версии 1.21.11.  

### Какую проблему решает  

Язык Neniy решает проблему обратной совместимости. Он транслируется в mcfunction для нужной версии майнкрафта.  

### Для чего создается  

Создается специально для моей карты в майнкрафте, чтобы она была переносимой на любую новую версию, как только она выходит.
